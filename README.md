# weather-app

Description
This is a Weather App that uses an API key to fetch real-time weather data. Users can get temperature, pressure,climate, and weather conditions by entering a city name.

Technologies Used
- Python
- Tkinter
- OpenWeatherMap API

Features
- Search weather by city name
- Shows temperature
- Shows pressure
- Shows climate
- Shows weather condition

How to Run
1. Install Python.
2. Add your API key.
3. Run the program.
